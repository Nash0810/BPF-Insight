RULE DETECTIONS
----------------

1. R10 (Frame Pointer) writes - CRITICAL
2. Pointer arithmetic violations - CRITICAL
3. Map lookup without null check - CRITICAL
4. Map update without key validation - CRITICAL
5. Bitwise/shift operations on pointers - CRITICAL
6. Unknown helpers (no BTF) - CRITICAL
7. Suspicious shift amounts (≥32 bits) - MEDIUM
8. Stack variable offset violations - CRITICAL
9. Multiple helper chains - MEDIUM
10. High block complexity - LOW
11. Missing BTF (for BTF-dependent helpers) - CRITICAL

TROUBLESHOOTING
---------------

Q: "Permission denied" when running bpfva?
A: The binary needs execute permission: chmod +x bpfva-linux-amd64

Q: "command not found" after installation?
A: Ensure /usr/local/bin is in your PATH: echo $PATH

Q: CFG visualization not rendering to PNG?
A: Install Graphviz: sudo apt-get install graphviz

Q: Cannot open ELF file: No such file or directory?
A: Ensure the file exists and is a valid eBPF object: readelf -h file.o
